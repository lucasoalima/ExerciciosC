## 📚 What's inside

### `ATIV_01_LUCAS_LIMA/` — arrays/vectors
- **ex_01** — read the daily average temperature for every day of September into a vector, then report each day's average, the month's average, and how many days were below the monthly average.
- **ex_02** — read the number of cars crossing a toll for 30 days into a vector and find the busiest day and its count.
- **ex_04** — additional vector-processing exercise.

### `ATIV_02_LUCAS_LIMA/` — functions & structs
- **EX_01** — a function that computes a consortium member's outstanding balance from total instalments, instalments paid and current instalment value.
- **EX_03 / EX_04** — define a `struct` for an employee (name, 8-char registration code, …) and process the records.

### `ExerciciosBimestral/` & `Exercicios_2Bimestre/`
- 10 console exercises per term covering conditionals, loops, arrays and basic math,
  plus an exam exercise (`Ex_prova.cpp`).

## 🚀 Compile & run
```bash
g++ "ATIV_01_LUCAS_LIMA/ex_01.cpp" -o ex01 && ./ex01
```
> Some files use Windows headers (`conio.h`); on Linux/macOS remove `conio.h` / `getch()` or use a loop/`system("pause")` alternative.
