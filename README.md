## 📝 About
Organized by activity and term (bimestre). Each folder holds small, self-contained
console programs focused on a specific logic topic.

## 🚀 How to compile & run
```bash
gcc path/to/exercise.c -o exercise   # or: g++ file.cpp -o exercise
./exercise
```

## 📁 Structure
```
ExerciciosC/
├── ATIV_01_LUCAS_LIMA/      # activity 1
├── ATIV_02_LUCAS_LIMA/      # activity 2
├── ExerciciosBimestral/     # term exercises
└── Exercicios_2Bimestre/    # 2nd term exercises
```
